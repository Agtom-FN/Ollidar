Old flow 7 steps to first data

  1. Open Capture, pick device tab
  2. Type lidar IP + host IP by hand
  3. Popup: run self-test, wait for gate
  4. Popup: create / name project first
  5. Choose profile, toggle Live on
  6. Start recording
  7. Display settings in a separate dialog

New flow 2 steps · zero popups

  1. Open Capture — auto-detect + connect + live preview happen by themselves; tune point size, gamma, brightness, refresh rate on the live cloud
  2. Press Start — a new project is created for you (name optional, auto-named otherwise); live view stays on while recording; Stop seals it into Projects

◎ detecting… AR · INITIALIZING

Mount the D6 on the phone's back, fan vertical, cameras clear. The phone's motion tracking (camera + IMU) is the D6's brain — it turns the vertical fan into a full 3D scan as you walk.

  • D6 = 3D scanner, phone-only. no built-in IMU (owner-verified) — so the phone supplies the motion path via ARCore. The app auto-starts tracking the moment a D6 capture opens and records poses + lidar together in the same project.
  • Tracking chip stays visible during preview and capture: INITIALIZING → TRACKING → LOST. 3D quality depends on it, so it is never hidden in a sheet.
  • Same 2-step flow as desktop: open Capture (auto-detect → live preview, sliders live) → Start. Empty name → Scan-016-2026-08-17-20-41.
  • Sheets, not popups. Display / Capture / Diagnostics slide up in place — nothing blocks the live view.
  • Mid-360 on the phone keeps the identical flow via the USB-C Ethernet adapter — auto-detect finds it the same way as on desktop.
