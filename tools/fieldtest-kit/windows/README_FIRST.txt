EQUIPMENT TEST - WINDOWS
=========================

Thank you for doing this. It takes about five minutes and the program
tells you what to do at every step. Nothing gets installed on your
computer.


WHAT YOU HAVE
  1. A small silver/black lidar that SPINS, on a USB cable.
  2. A bigger round lidar, with a NETWORK cable and a 12 volt power lead.
  3. A GPS board with one or two ANTENNAS that screw on, on a USB cable.

You can test them one at a time. You do not need all three at once.


STEP 1  PLUG IN WHAT YOU HAVE
  - Small lidar: plug its USB cable into the computer.
  - Big round lidar: connect its 12 volt power AND put its network cable
    into the computer's network socket (or into a USB-to-network adapter).
  - GPS: screw the antenna onto the socket marked ANT1 and put the
    antenna OUTSIDE or right against a window. Then plug in its USB.

  First time only: wait about a minute after plugging in. Windows sets
  up the USB parts by itself if the computer is on the internet.


STEP 2  DOUBLE-CLICK "START_TEST"
  It is in this folder.

  If a blue box says "Windows protected your PC":
      click the small text  More info , then the button  Run anyway .

  A black window opens with a menu. Type a number and press ENTER:

      1  small spinning lidar          about half a minute
      2  big round lidar               about a minute
      3  GPS receiver                  about two minutes
      4  TEST EVERYTHING   <-- pick this if you are not sure
      Q  finish


STEP 3  SEND THE RESULT BACK
  A folder called  LIDAR_TEST_RESULT  appears on your Desktop.
  Send that WHOLE folder back the same way you got this test -
  WhatsApp, WeChat or email. That's everything.


THINGS THAT MIGHT COME UP
  "Do you want to allow this app to make changes?"
      This is only for the big round lidar. It sets the computer's
      network address so the lidar can be heard. Click YES.
      Afterwards the program tells you how to undo it. IMPORTANT: if you
      say yes, that network cable will not give you internet until you
      set it back - the program prints exactly how.

  The GPS says PARTLY WORKED / no satellites
      The antenna cannot see enough sky. Put it outdoors or right on a
      windowsill, wait two minutes, run test 3 again. Send the result
      folder either way.

  The GPS says SINGLE and not RTK
      That is CORRECT for this test. Centimetre-accurate RTK needs an
      internet correction service that we are not using yet.

  Something else went wrong
      The window explains what to try, in order. If it still fails:
      take a PHOTO of the whole window with your phone and send the
      photo along with the Desktop folder. That is always useful to us.


WHAT THIS PROGRAM DOES AND DOES NOT DO
  It only LISTENS to the equipment and saves what it hears. It does not
  install anything, does not change any setting except the one network
  address it asks you about first, and does not send anything anywhere -
  you send the folder yourself.
