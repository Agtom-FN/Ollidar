Connecting a COIN-D6 over USB

The COIN-D6 lidar presents itself as a USB-to-serial adapter built around a WCH CH340 chip. LidarScan talks to it as a plain COM port at 230400 8N1 — no vendor software or SDK is involved.

Try it before installing anything. Windows 10 and Windows 11 ship an in-box CH340 driver, and on most machines the device works the moment you plug it in. Install the WCH driver only if the steps below show it is missing.

1. Plug it in and check

  1. Connect the D6 with a data USB cable (charge-only cables are a common cause of "nothing happens").
  2. Press Win+X and open Device Manager.
  3. Look under Ports (COM & LPT) for USB-SERIAL CH340 (COMn).

If you see it — you are done. Open LidarScan, go to Capture → COIN-D6, and that COMn will be in the port list. Run Test device before recording; it passes when the sensor is delivering at least 3,000 points/second.

2. If the driver is missing

A missing driver shows up as an entry with a yellow warning triangle under Other devices, usually named USB2.0-Serial or Unknown device.

  1. Download CH341SER.EXE from WCH, the chip vendor:
    https://www.wch-ic.com/downloads/CH341SER_EXE.html
  2. Run it and press INSTALL.
  3. Unplug the D6, plug it back in, and re-check Device Manager.
Why LidarScan does not bundle this driver. CH341SER.EXE is WCH's own redistributable, it is updated independently of this app, and a stale bundled copy is worse than none — it can downgrade a working in-box driver. Getting it from the vendor means you always get the current, vendor-signed version.

3. Counterfeit CH340 chips

Some cheap adapters carry cloned CH340s that the official driver refuses. Symptom: the port appears but opening it fails, or it disappears after a few seconds. If the D6's own cable does this, contact your supplier — it is a hardware problem, not a LidarScan one.

4. Which COM port is it?

If several serial devices are attached, unplug the D6, note the ports listed, plug it back in, and take the one that appeared. LidarScan's port picker also shows the USB vendor/product IDs and flags CH340-based adapters, so the D6 is usually obvious there too.

Mid-360 users

The Livox Mid-360 does not use USB at all — it is Ethernet. No driver is needed; what it needs is a static IP on the adapter it is plugged into. LidarScan's Mid-360 capture tab has the settings and a self-test.
