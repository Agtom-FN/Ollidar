# `desktop/packaging/` — what is in here

Per-OS installer inputs for C8. The **procedure**, the reasoning and the real
signing/notarization steps are in **[`PACKAGING.md`](PACKAGING.md)**; this file
is just the map.

```
packaging/
  PACKAGING.md            ← read this one
  Info.plist.in           macOS bundle metadata (C7 wrote it, C8 wired it up)
  macos/
    lidarscan.icns        app icon        ) generated by tools/make_icon.sh,
    lidarscan.png         1024x1024 master) committed as build inputs
    entitlements.plist    hardened-runtime entitlements for a Developer ID build
  windows/
    lidarscan.nsi         NSIS 3 installer script
    build_installer.ps1   build + windeployqt + makensis
    CH340-driver.html     the COIN-D6 USB driver pointer page the installer ships
    LICENSE.txt           installer licence page + third-party notices (Qt LGPLv3 etc.)
    lidarscan.ico
  linux/
    build_appimage.sh     linuxdeploy + the qt plugin
    build_deb.sh          dpkg-deb
    debian-control.in     .deb metadata (Depends, description)
    debian-postinst       udev reload + MIME/desktop/icon cache refresh
    debian-postrm         the same caches on removal
    lidarscan.desktop     desktop entry (forces QT_QPA_PLATFORM=xcb — see below)
    lidarscan.xml         shared-mime-info for .lscan / .lscan.zip
    99-lidarscan.rules    udev rule for the CH340 (and FTDI) USB serial adapter
    README-udev.txt       shipped inside the AppImage, which cannot install the rule
    lidarscan.png
  ci/
    README.md             how to merge these into .github/workflows/
    macos-dmg.yml.snippet
    windows-installer.yml.snippet
    linux-packages.yml.snippet
```

The macOS build scripts live in `desktop/tools/` rather than here, next to the
existing `fetch_filament.sh`:

```
tools/
  fetch_filament.sh         (pre-existing) arm64 Filament release
  build_filament_x86_64.sh  the missing x86_64 slice, from source
  make_universal_filament.sh lipo the two into filament-universal/
  fetch_qt_universal.sh     official universal Qt via aqtinstall
  make_icon.sh              the icons above, from a stdlib-only PNG writer
  package_macos.sh          universal .app + DMG
```

## Honest status

| | Built? | Run? |
| --- | --- | --- |
| macOS DMG | **yes** — `dist/LidarScan-0.1.0-universal.dmg`, both slices | **yes** — mounted and launched, arm64 *and* x86_64 |
| Windows installer | no | no — `lidarscan.nsi` is `makensis`-validated only |
| Linux AppImage / .deb | no | no — `.desktop`/MIME XML validated only |

Windows and Linux are staged because **neither renderer has ever been compiled**
(`../NOTES.md` §3.1). Working installers for an app that does not build are
groundwork, not a deliverable.

## Two things worth knowing before you touch this

* **`lidarscan.desktop` sets `QT_QPA_PLATFORM=xcb` deliberately.**
  `src/render/NativeSurface_linux.cpp` refuses a Wayland surface outright, so on
  a default Ubuntu/Fedora session the 3D viewport will not appear without
  XWayland. Do not "clean this up".
* **The Windows installer does not claim `.zip`.** Windows has no `.lscan.zip`
  extension — only `.zip` — and taking it would hijack every archive on the
  machine. `.lscan.zip` is exposed as an *Open With* entry instead. See
  `PACKAGING.md` §2.
